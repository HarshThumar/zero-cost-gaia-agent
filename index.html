What it can do

  • Search the web and read pages, PDFs and historical Wikipedia revisions
  • Read Excel, CSV, Word and code attachments, and run Python for exact calculations
  • Transcribe audio with Whisper and analyse YouTube videos frame by frame
  • Read a chess board from an image, one square at a time, and find the best move with Stockfish
  • Answer each question 3 times and submit the majority answer
